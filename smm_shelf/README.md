# smm_shelf — Abstract Goods Sort

Играбельная демка механики Goods Sort в стиле стеклянного 3D: красное стекло, frosted-белые плашки, хром.

- Поле 3×6, по 3 места на полке; три одинаковые фигуры на полке сгорают, за ними появляется следующий слой.
- Таймер 4:00, комбо, бустеры: подсказка, магнит, микс, заморозка.
- Фигуры рендерятся в браузере через Three.js (r149, jsDelivr) в спрайты. Всё в одном `index.html`, сборка не нужна — открой файл или раздай через GitHub Pages.
